# Demo Walkthrough（示例演示手册）

## 项目是什么

Conan VPS Control Tower 是一个个人 VPS 代理节点的只读健康观察层，不做任何代理配置写入，不做自动修复。默认通过 `127.0.0.1:3001` 提供 Dashboard。

## It is not

本项目不是：

- 3X-UI 的替代品
- 代理控制台
- 自动重连/自动重启工具
- 防火墙管理工具
- 账单系统

## 如何打开 Dashboard

```bash
ssh -L 3001:127.0.0.1:3001 dmit-control-tower
```

在本机浏览器打开：

```text
http://127.0.0.1:3001
```

## 第一屏怎么看

首页以中文卡片展示为主，重点优先看：

- 总体状态
- 代理链路
- 诊断摘要
- 活跃风险

## 如何理解总体状态

- `健康`：目前已检查项中没有明显异常。
- `警告`：有轻度风险，需要关注。
- `降级` / `严重`：建议先确认代理链路和服务状态。
- `未知`：某项暂时读取失败或未配置，不一定表示故障。

## 如何理解代理链路

代理链路展示了关键路径顺序：

1. VPS 健康
2. 代理核心运行
3. 3X-UI 面板可达
4. 代理端口开放

如果链路中有红色/风险点，优先对应到对应层检查。

## 如何理解活跃风险

“活跃风险”只显示真正 warning/degraded/critical 的检查项，不把“未配置”当作风险。

- 有风险 → 看对应标题和建议首条命令。
- 无风险 → 显示“当前没有活跃风险”。

## 如何理解未配置检查项

未配置项（如 Domain / DNS、TLS 证书）不会影响总体健康判定，但会提示“尚未配置”。
这是为了提醒你未来是否需要补充配置。

## 如何理解诊断建议

- 先看“诊断摘要”中的重点项。
- 如果异常，查看完整诊断区块获取：
  - 影响范围（impact）
  - 可能原因（likely cause）
  - 建议第一检查项（suggested first check）
  - 只读命令清单

## 如何理解告警关闭

告警默认关闭（`alerts.enabled = false`）：

- 不会主动发送 Telegram/Email。
- 可在 `测试告警` 中看到“disabled/skipped”提示。
- 页面上不会触发任何自动修复动作。

## 如何确认没有公网暴露

检查服务监听：

```bash
ss -lntup | grep 3001
```

期望只看到：

```text
127.0.0.1:3001
```

并且不存在：

```text
0.0.0.0:3001
```
