# README for media assets

This folder stores light, local-only documentation assets for Conan VPS Control Tower.

Guidelines:

- Do not store real environment-sensitive data in images or filenames.
- Do not expose real host, credentials, identity values, or account references in screenshots or docs.
- Screenshots should prioritize showing the local-only and read-only workflow.
- Keep examples de-identified (`127.0.0.1`, `YOUR_VPS_HOST`, `YOUR_DOMAIN`).
