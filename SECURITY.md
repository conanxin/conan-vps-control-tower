# Security

Please do not submit sensitive information in issues, pull requests, screenshots, logs, or examples.

Do not post:

- Real VPS IP addresses
- Private domains
- Tokens
- Proxy UUIDs
- Subscription links
- 3X-UI panel passwords
- Proxy node plaintext configuration

The project defaults to `127.0.0.1:3001` and is intended for local use or access through an SSH tunnel. Direct public exposure is not recommended.

To report a security issue, open a GitHub issue with a non-sensitive reproduction description. If a private reporting channel is added later, this document will be updated.
